# Локальный AI-бот в терминале

Консольный чат-бот на Python. Он отправляет сообщения нейросети через OpenAI-совместимый API и печатает ответ прямо в терминале.

## Что делает проект

- Ведёт диалог с языковой моделью, помнит последние реплики (контекст).
- Работает с несколькими провайдерами через один клиент: Ollama (локально и бесплатно), OpenRouter, DeepSeek, ProxyAPI.
- Печатает ответ по мере генерации (стриминг) или целиком (`--no-stream`).
- Показывает время ответа, число токенов и размер контекста.
- Сохраняет переписку в Markdown-файл `logs/dialog.md`, из него удобно взять скриншот для сдачи ДЗ.
- Проверяет при старте, что провайдер доступен и модель найдена.

## Что сделано (по домашнему заданию)

В задании два варианта: базовый (по инструкции урока) и продвинутый (своя тема и кастомная логика). Здесь реализована адаптированная версия: вместо VK-бота сделан консольный бот, а ИИ-часть, настройка провайдера и обработка ошибок собраны по материалам урока.

- Подключена локальная бесплатная модель через Ollama (`qwen3.5:latest`). Остальные провайдеры включаются через `.env`.
- Исправлены проблемы с кодировкой Windows-консоли: вывод принудительно переключается на UTF-8, поэтому символы вроде `↳` и кириллица не ломают программу.
- Добавлена своя логика:
  - служебные команды `/help`, `/reset`, `/history`, `/model`, `/system`, `/exit`;
  - системный промпт (роль ассистента) меняется через `.env` или флаг `--system`;
  - разовый вопрос из командной строки без входа в чат;
  - понятные сообщения об ошибках вместо трейсбека (таймаут, лимит, нет связи с провайдером);
  - журнал диалога и настраиваемые параметры (температура, лимит токенов, длина истории).
